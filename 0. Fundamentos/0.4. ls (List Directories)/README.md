# 📃 `ls` (List Directories)

Ahora q sabemos movernos por el sistema de archivos vamos a ver **qué contienen** dichos directorios dentro! Si escribes en tu terminal `ls` y pulsas enter verás todo lo que contiene el sitio en el que te encuentras. Si quieres ver lo que contiene otra ruta, escribe `ls seguido/de/tu/ruta`!

Para ver **archivos ocultos** usamos `ls -a`, _esa a viene de all (todos)_.

Si quieres ver una **lista bien detallada** de tus archivos usa `ls -l`, _la l es de long (largo)_, así que la verás en formato... exacto, largo xd

A veces te gustaria **cambiar el orden en el que aparecen tus archivos**? Nite, tenemos `ls -r`, _r de reverse (al revés)_, de esta forma verás el último item de una lista enorme arribita del todo :3

Por supuesto, puedes combinar estas letritas, por ejemplo `ls -la`, no importa el orden aquí, puedes poner `ls -al`y seria lo mismitico! Literal puedes hacer un `ls -lar` si te sale del alma xd
