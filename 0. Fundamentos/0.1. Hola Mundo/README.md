# 👋🏻 Hola Mundo

Cuando abres la **terminal** lo primero que veras sera tu usuario seguido del directorio en el que se encuentra, por ejemplo:

```bash
sugus@Kali:/home/sugus $
```

El simbolito de `$` indica que esta ready para aceptar comandos de un usuario regular, mera información!

Sin miedo, toca usarla! Escribe en la terminal lo siguiente, verás como te muestra (o hace "eco") del texto que le has dado ;D

```bash
echo Hola Mundooo
```

> Esto sería todo! A que no da tanto miedo una terminal? :P
